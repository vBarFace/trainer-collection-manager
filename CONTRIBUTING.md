# Contributing

Thank you for contributing. Discuss substantial changes in an issue before implementation. Use a focused branch, write tests for observable behavior, and keep code and documentation in English.

Before opening a PR, run `npm ci`, `npm run check`, `npm run rust:fmt`, and `npm run rust:check`.

Do not include player data, screenshots, secrets, build artefacts, copyrighted Pokémon material, datasets, or model weights. By contributing, you agree to license your original contribution under MIT.
