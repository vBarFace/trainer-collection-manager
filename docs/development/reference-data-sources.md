# Reference source research

Reviewed: 2026-10-26. Scope: potential offline Pokémon GO reference snapshots, without private game APIs, authenticated access, scraping the game or downloading game assets into the repository.

## Result

Use the task's compliant fallback: a provider-independent validated local catalog interface, an original empty production manifest and fictional test fixtures. None of the reviewed sources supplied sufficient evidence of redistribution rights for the underlying GO dataset. This is a limitation of the evidence reviewed, not a conclusion that all redistribution is unlawful. Public access, a caching recommendation or a software license alone does not establish the required dataset rights.

PvPoke is the preferred future normalized adapter candidate, conditional on dataset-specific rights clarification, provenance review and verification of a bounded subset. It is not selected as a bundled dataset today. No species, types, stats, relationships, sprites or artwork from these sources are shipped. [Implementation and update procedure](reference-data.md) and [decision 0006](../decisions/0006-versioned-local-reference-data.md) describe the fallback.

## Correctness and semantic limitations

- PvPoke simulation records can include separate Shadow entries. A future adapter must deliberately separate individual Shadow/Purified status from species and GO form identity. Shiny and Lucky must also remain individual properties. Regional, Mega and costume semantics need source-backed normalization rather than one generic variant flag.
- PvPoke's `baseStats.hp` must be normalized to GO base Stamina, not observed HP or the player's HP IV. Single types must omit upstream placeholder values such as `none`.
- An [open PvPoke family-data report](https://github.com/pvpoke/pvpoke/issues/399), opened 2026-10-09, alleges incorrect/missing relationships. This is an unverified user report, not proof of an error; it reinforces the need to verify relationships rather than treat all family links as authoritative evolution metadata.
- Missing evolution links or costs do not mean no evolution or no requirement. Preserve unknowns explicitly. Descriptive requirements in the foundation are not executable eligibility or investment rules.
- Dataset structural validation does not establish factual correctness, completeness, redistribution permission or source freshness. All four require a separate source-backed review before releasing real records.

## Future integration evidence

Retain the applicable dataset-specific permission/license, provenance chain, source URLs, retrieval date, pinned upstream revision, content digest and required notices. Preserve stable normalized IDs across updates; test renamed/removed identities and incomplete snapshots. Verify representative GO types, Attack/Defense/Stamina, forms and evolution requirements against permitted sources. A bounded, correctly licensed snapshot is preferable to a complete-looking but unsupported catalog.

## Task 007 evidence review — 2026-10-26

The licensing gate remains **blocked**. This is an evidence decision under the project's release requirements, not a legal determination that redistribution is prohibited. No rights holder was contacted. No real game records or third-party assets were committed. The adapter now supports the PvPoke file shape using original fictional fixtures; there is no authorized real-data release plan.

- **PvPoke technical baseline:** inspected immutable revision [`38f70320d190e38c2e6c778f572662b4c4e8185d`](https://github.com/pvpoke/pvpoke/commit/38f70320d190e38c2e6c778f572662b4c4e8185d), dated 2026-10-23. The [record file](https://github.com/pvpoke/pvpoke/blob/38f70320d190e38c2e6c778f572662b4c4e8185d/src/data/gamemaster/pokemon.json) has 1,751 simulation entries, not 1,751 distinct species or a claim of complete released GO coverage. It exposes Dex, per-variant IDs/names, `atk`/`def`/`hp`, type pairs (including a second-slot `none`), tags and optional family/form-change fields. [Runtime stat handling](https://github.com/pvpoke/pvpoke/blob/38f70320d190e38c2e6c778f572662b4c4e8185d/src/js/pokemon/Pokemon.js) uses base HP plus HP IV before the level multiplier; this supports interpreting `baseStats.hp` as GO base Stamina, separate from observed HP/IVs. This verifies field semantics, not each record's factual accuracy. Names, form identity, aliases and relationships still need individual review. The [README](https://github.com/pvpoke/pvpoke/blob/38f70320d190e38c2e6c778f572662b4c4e8185d/README.md) describes volunteer maintenance, a nominal fortnightly cycle and incomplete Game Master data. Recent commits establish activity, not a freshness guarantee.
- **PvPoke rights:** the [MIT license](https://github.com/pvpoke/pvpoke/blob/38f70320d190e38c2e6c778f572662b4c4e8185d/LICENSE) identifies the software author, requires retention of its notice and disclaims warranties. Neither that file nor the reviewed README establishes a dataset-specific grant from the owners of underlying game content or a complete authority/provenance chain. Retaining MIT attribution alone does not satisfy this release gate. PvPoke is selected for adapter ergonomics and immutable Git history, conditionally, rather than as an approved bundled provider.
- **PokeMiners:** inspected revision [`8e227be44f288d34463e23bf04e9b564d3c16f79`](https://github.com/PokeMiners/game_masters/commit/8e227be44f288d34463e23bf04e9b564d3c16f79), dated 2026-08-29. Its [README](https://github.com/PokeMiners/game_masters/blob/8e227be44f288d34463e23bf04e9b564d3c16f79/README.md) describes raw historical configurations and timestamped updates, warns that obfuscated field names may change or be uncertain, attributes ownership to The Pokémon Company/Niantic and limits its stated purpose to education. No explicit downstream dataset redistribution permission was established. Raw coverage is richer than this adapter needs, with greater normalization uncertainty; no freshness/completeness guarantee was verified.
- **PoGoAPI:** the [documentation](https://pogoapi.net/documentation/) separates GO stats/types/evolution endpoints and provides hashes for cached copies, but mutable API files are less convenient than Git commits for this release workflow. The [legal notice](https://pogoapi.net/Legal/), reviewed 2026-10-26, invokes fair use and warns about accuracy; it supplies no explicit underlying-data downstream redistribution grant. Caching advice is not that grant. No separate dataset license, authoritative ownership chain or maintenance SLA was established.

To unblock a real snapshot, retain a dataset-specific license/authorization and provenance chain establishing authority over the exact included fields, permitted downstream distribution/derivatives and applicable notices. Independently verify each bounded species/form, GO stats/types and any asserted evolution group. Record the exact authorized revision, retrieval date and source/output digests using the adapter workflow. A reviewer must approve the evidence and mappings before bundling. Until then, real-data acceptance remains blocked and synthetic output must never replace the production empty catalog.

Competitive rankings, raid counters, teams and investment optimization remain separate work requiring tested game mechanics and individual inputs.
