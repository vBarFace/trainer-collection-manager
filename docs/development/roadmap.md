# Development roadmap

1. Implemented (Task 002): local inventory schema, stable UUIDs, validation, grouped optional appraisal IVs, standard/custom tags and typed Rust persistence.
2. Implemented (Task 003): native PNG/JPEG selection, bounded temporary preview, manual review, explicit atomic confirmed saving and a minimal persistent Inventory list. OCR and automatic extraction are deferred.
3. Future: review OCR requirements independently, then versioned deterministic analysis and explainable recommendations; only then consider optional local AI proposals behind typed preview tools. Full editing, deletion, filtering and custom-tag management UI are outside Task 003.

Each milestone requires separate product, security and license review.
